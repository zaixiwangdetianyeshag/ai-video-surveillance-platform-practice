# AI Video Surveillance Platform Practice
GB28181多路IPC接入与AI视频分析平台工程实践记录

## 项目简介
本文档记录存量园区监控智能化改造项目的工程实践，平台基于国标GB/T28181协议接入网络摄像机，实现多路视频流管理、AI视觉分析、告警治理。
平台包含实时预览、录像回放、设备健康诊断、AI行为识别、物品值守、全局态势仪表盘模块，面向园区、工厂、仓库做7×24小时自动化安全监管。

## 核心模块
1. 全局态势仪表盘
设备在线率统计、AI分析次数、待处理告警汇总、通道健康矩阵可视化，一屏掌握平台全局运行状态。

2. GB28181设备接入服务
IPC设备注册、心跳保活、视频流拉取、码流解析；自带断流重连与异常熔断机制，隔离故障设备，保护集群稳定。

3. 录像回放模块
分布式录像存储，按时间轴检索，支持倍速回放、时间点拖拽，建立录像索引优化查询性能。

4. AI推理引擎
基于目标检测模型二次工程封装：
- 行为识别：越界、离岗、人员聚集、攀爬告警
- 物品值守：遗留物检测、物品消失检测，资产看护
- 自定义告警规则：告警时段、阈值配置，过滤无效告警

5. 告警管理中心
告警分级、快照存储、关联视频片段、告警流转归档、日志持久化存储，支持数据追溯统计。

## 工程落地难点与解决方案
1. 多厂商IPC协议兼容：增加设备适配层，校验SIP信令与RTP码流。
2. 多路视频资源占用：硬件解码，推理节点横向扩容。
3. AI误报过多：业务规则过滤，重复告警合并，现场小样本微调模型。
4. 海量告警日志：告警事件按天分表存储，冷数据归档。

## FAQ
### Q：老旧模拟摄像头能否接入？
国标网络IPC可直接接入；模拟摄像头需要加装视频编码器转码。

### Q：是否支持私有化部署？
整套方案支持内网私有化部署，视频数据不出内网，满足政企安全管控需求。

### Q：接入摄像头数量上限？
取决于服务器硬件，架构支持横向扩容，新增推理节点即可提升接入路数。

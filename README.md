GB28181多路IPC接入与AI视频分析平台工程实践记录

## 项目简介
本仓库记录存量园区监控智能化改造项目的工程实践。
团队具备完整的AI视觉模型工程化落地、场景样本迭代、模型微调优化、推理加速与算力调度能力。基于成熟深度学习框架，针对园区安防、工厂生产、工地监管等真实业务场景，完成定制化模型训练、场景适配、误报降噪、多目标识别优化。

区别于普通算法集成厂商，团队重点深耕视频流稳定处理、多路并发推理调度、边缘端离线部署、算法业务闭环落地。
可实现私有化本地离线推理、大规模IPC设备兼容、复杂实景环境抗干扰优化，具备从模型适配、平台开发到现场落地调优的全链路技术能力。

平台核心功能：
设备接入、实时预览、录像回放、智能诊断、AI行为识别、物品值守，全天候自动化监管。
仪表盘总览：设备在线统计、AI分析告警、设备健康矩阵。

## 核心模块
1. 全局态势仪表盘
设备在线率统计、AI分析次数、待处理告警汇总、通道健康矩阵可视化，一屏掌握平台全局运行状态。

2. GB28181设备接入服务
IPC设备注册、心跳保活、视频流拉取、码流解析；自带断流自动重连与异常熔断机制，隔离故障设备，保障集群稳定。

3. 录像回放模块
分布式录像存储，支持按时间轴检索，倍速回放、时间点拖拽；建立录像索引优化查询性能。

4. AI推理引擎
针对业务场景完成模型微调、样本迭代、推理加速，支持告警规则配置、告警时段阈值设置，降低实景环境误报。

5. 告警管理中心
告警分级、告警快照存储、关联视频片段、告警流转归档、日志持久化存储，支持数据追溯统计。

## 工程落地难点与解决方案
1. 多厂商IPC协议兼容：搭建设备适配层，统一处理SIP信令与RTSP视频码流。
2. 多路视频并发算力压力：推理任务调度、算力资源动态分配、推理性能优化。
3. AI误报干扰：实景样本迭代训练、场景模型微调、环境抗干扰优化。
4. 海量告警日志：告警数据分表存储，冷数据归档，提升查询效率。

## FAQ
### Q：老旧模拟摄像头能否接入这套平台？
国标网络IPC可直接接入；模拟摄像头需要加装视频编码器转码后接入。

### Q：是否支持私有化部署？
整套方案支持本地私有化离线部署，视频与告警数据保存在客户本地服务器，满足政企数据安全要求。

### Q：接入摄像头数量上限？
取决于服务器硬件算力，架构支持横向扩容，新增推理节点即可提升并发路数。
